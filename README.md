# Dispatcher 3.1

Google Apps Script для производственного диспетчера.

## Структура

- `Main.gs` — onEdit, FIFO-очередь событий и маршрутизация по этапам.
- `Config.gs` — номера столбцов, ID внешних таблиц и ленивая конфигурация Firestore.
- `Helper.gs` — общие операции с листами, UUID, checkbox-validation и формирование строк Базы.
- `Развертывание спецификации.gs` — Firestore и развёртывание спецификаций.
- `Удаление спецификации.gs` — сворачивание развёрнутых спецификаций.
- Файлы этапов (`Склад.gs`, `Производство.gs` и т. д.) — специальная бизнес-логика соответствующего этапа.
- `Diagnostics.gs` — ручные тесты и диагностика. Функции, изменяющие данные, отмечены в комментариях.

## Важные ограничения текущего рефакторинга

Performance-refactor не меняет формульную архитектуру Google Sheets и существующие QUERY-листы. Исторические константы столбцов AL:AN сохранены для совместимости; их семантика должна быть отдельно сверена с текущими заголовками таблицы.

`Изменение состава листов.gs` содержит legacy-утилиту восстановления минимального шаблона листов. До отдельного рефакторинга архитектуры таблицы её не следует использовать для массового перестроения существующих рабочих листов.

## Диагностика

Ручные проверки собраны в `Diagnostics.gs`. Перед запуском функции прочитайте её комментарий: часть тестов только читает данные, часть может изменять Google Sheets или Firestore.
